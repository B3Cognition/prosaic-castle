Preserve license, provenance, legacy modules, tests and historic evidence.

The Prosaic provider is read-only, scoped, LanceDB-backed and FTS-first.
Dense retrieval and recency/rule boosts require explicit opt-in. Never weaken
namespace, wing, revision, exact-byte or provenance validation. No SOAR or model
execution belongs in the default provider path. Custom SOAR rules must be
inventoried and explicitly rejected by the deterministic profile, never ignored.

SUE is a separately installable pure engine. Runtime owns model execution and
usage. Harness owns accepted workflow state, frozen inputs and resume. Lab owns
authorization, optional workflows and evaluation. No SDK internals or copied
workflow engines. Memory and review remain independently disabled by default.

Use apply_patch and watched RED/GREEN tests. Preserve raw verification output.
Do not claim fixtures prove review quality or macOS qualifies native Linux.
No live inference is authorized. Disjoint independent agent work is authorized.
